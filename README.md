# Work requirement 4

A Module 6 assignment using SQLite to store 10 fictional books, 5 authors,
and 20 quotes.

## SQL files

- `01-schema.sql` creates the Books, Authors, and Quotes tables.
- `02-seed.sql` inserts sample data.
- `03-queries.sql` counts quotes per book and author and retrieves quotes
  for a specific book or author.
